# One Star, Five Stars for the Food

Entry for the make.fun bounty [One Star, Five Stars for the Food](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7): one sentence (at most 200 characters) in the voice of an alien tourist giving planet Earth a one-star review while slipping in a genuine compliment about the food.
